## 시나리오 1 — 퇴근 후 갑작스런 약속 (단발성)

**페르소나:** 지수 (P1)
**상황:** 금요일 오후 5시. 친구 둘과 갑자기 저녁 약속이 잡혔다.

1. 지수가 카톡 단톡방에서 "오늘 7시 강남역 OO식당 콜?" 메시지를 받음
2. MeetPod 앱 열어 **"+ 새 약속"** 탭
3. 그룹 선택 안 하고 **1회성 약속** 으로 진행
4. 친구 목록에서 두 명 선택 (검색 없이 평소 자주 만나는 친구가 위에)
5. 장소 picker → "OO식당" 검색 → Google Maps에서 핀 선택
6. 시간 19:00~21:00, 위치공유 시작 시각은 기본값 20분 전 그대로
7. 본인 알림 "30분 전" 추가
8. 저장 → 두 친구에게 푸시 알림 발송, 약속 채팅방 자동 생성
9. 18:40 — 지수 모바일이 자동으로 백그라운드 위치 공유 시작
10. 18:55 — 지수가 "거의 다 왔어" 하려다 보니 친구 둘 다 이미 도착 핀이 식당에 표시됨. 메시지 안 보내고 바로 입장

**가치 포인트:** "어디야?" 카톡 없이 도착 확인. 끝나면 자동으로 위치 공유 OFF.

## 시나리오 2 — 대학 동기 동창회 (그룹 + 약속)

**페르소나:** 민호 (P2)
**상황:** 학과 동기 15명 단체. 1년 만에 모임.

1. 민호가 **"대학동기"** 그룹 생성, 본인이 방장
2. 초대 링크 생성 → 학과 단톡방에 공유. 7일 만료, 최대 20회 사용
3. 12명 가입 완료. 못 들어온 3명은 링크 만료 전 재공유
4. 민호가 그룹 내에서 **"5/15 토요일 동창회"** 약속 생성
5. 멤버 picker: 그룹 12명 전원 default 체크. 출장인 한 명만 체크 해제
6. 장소: 홍대 OO술집. 위치공유 시작은 30분 전으로 변경 (먼 데서 오는 친구 위함)
7. 약속 채팅방 자동 생성 → "각자 오는 길에 사진 찍어 올리자ㅋㅋ" 분위기 형성
8. 당일 오후, 어떤 친구가 술집 옆에 있는 더 좋은 가게를 발견하고 **장소 카드** 로 약속 채팅에 공유
9. 민호가 약속 편집해서 장소 변경 → 모든 참여자에게 푸시 변경 알림
10. 모임 시작. 지도에서 누가 어디쯤인지 한눈에. 늦는 친구는 "5분만 기다려줘" 채팅
11. 모임 끝. 채팅방 자동 아카이브. 그룹 상시 채팅방은 그대로 유지되어 "다음 모임 언제?" 대화 이어짐

**가치 포인트:** 큰 그룹 조율, 장소 변경 푸시, 그룹과 약속 채팅 분리.

## 시나리오 3 — 카페에서 만나기로 했는데 공사 중 (장소 변경)

**페르소나:** 서연 (P3)
**상황:** 육아맘 친구 3명과 평일 낮 카페 약속.

1. 일주일 전 약속 잡아놓음
2. 약속 당일 11:30 (12시 약속) — 위치공유 자동 시작
3. 한 친구가 카페 도착 → 공사 중으로 임시 휴업 발견
4. 친구가 약속 채팅방에 "여기 공사 중인데 ㅠㅠ 어떡하지" + 옆 카페 **장소 카드** 공유
5. 서연이 채팅 보고 즉시 약속 편집 → 새 카페로 장소 변경
6. 다른 멤버 모바일은 변경 푸시 + 지도 핀 자동 업데이트
7. 모두 새 카페로 도착. 위치공유 덕에 누가 가까이 왔는지 보여서 "5분 뒤 도착" 채팅 불필요

**가치 포인트:** 실시간 장소 변경, 채팅의 장소 카드, Realtime 핀 업데이트.

## 시나리오 4 — 등산 동호회 산행 (위치 공유의 진가)

**페르소나:** 태훈 (P4)
**상황:** 12명 등산 동호회 토요일 새벽 산행.

1. 태훈이 **"OO산악회"** 그룹 운영. 본인 owner, 부회장에게 admin 권한 위임
2. 산행 약속 생성: 토요일 06:00~14:00, 장소는 등산로 입구
3. 위치공유 시작 시각을 **60분 전** 으로 설정 (각자 픽업/이동 추적)
4. 새벽 5시 — 멤버들 모바일 자동 위치공유 시작. 누가 어디서 출발했는지 지도에서 확인
5. 06:00 — 정원 12명 중 11명 도착. 한 명이 늦음. 태훈이 지도 보니 아직 30분 거리
6. 약속 채팅에 "○○님 30분 늦으니 먼저 출발할게요" 공지
7. 산행 중 — 한 멤버가 컨디션 나빠져 조기 하산. 약속 채팅에 알림. 다른 멤버들이 지도에서 위치 확인 가능
8. 14:00 종료 → 자동 위치공유 OFF, 약속 채팅 아카이브
9. 그룹 상시 채팅에서 사진 공유 + "다음주 어디 갈까요?" 다음 약속 논의 시작

**가치 포인트:** 다인원 위치 가시성, 안전(조기 하산자 추적), owner/admin 권한 분리.

## 시나리오 5 — 친구가 길을 잃음 (안전)

**페르소나:** 지수 (P1) + 친구
**상황:** 처음 가는 동네에서 만나기로 함.

1. 약속 시간 10분 전. 지수는 도착, 친구는 아직 안 옴
2. 카톡으로 물어보려다 지도 보니 친구가 약속 장소 반대편 골목에 핀
3. 지수가 약속 채팅에 "네 위치 보이는데, 큰길로 나와서 오른쪽으로 와" + 본인 장소 다시 카드로 공유
4. 친구가 5분 후 도착. 전화 통화 없이 해결

**가치 포인트:** "전화 안 하고도 길 안내" — 일상의 작은 마찰 제거.

## 시나리오 6 — 신입생, 처음 약속 잡기 (온보딩)

**페르소나:** 혜진 (P5)
**상황:** 대학 신입생. 새 친구가 MeetPod 추천.

1. 친구가 카톡으로 초대 링크 보냄 → `meetpod://invite/abc12345`
2. 혜진이 링크 탭 → 앱스토어로 이동, 설치
3. 앱 열고 Kakao 로그인
4. 핸들 입력 화면 — `@hyejin22` 설정
5. 푸시 권한 허용
6. 자동으로 친구 추가 화면, "친구 신청 수락" 버튼 → 즉시 친구 추가
7. 친구가 만들어둔 신입생 환영회 약속에 자동 초대됨을 확인
8. 약속 상세 보고 "참여" 자동, 본인 알림 1시간 전으로 설정
9. 첫 약속 당일 — 위치공유 권한 요청 ("항상 허용" 권장) 후 자동 시작

**가치 포인트:** 가입~첫 약속 참여까지 마찰 최소화. 앱 처음 써도 막히는 곳 없음.

## 시나리오 7 — 사장님 비정기 회식 (다중 그룹)

**페르소나:** 준영 (P6)
**상황:** 자영업자 모임 두 곳 동시 운영 (지역상인회 + 동종업종 사장님).

1. 준영의 그룹 목록: "OO동 상인회" (25명), "치킨집사장모임" (8명)
2. 평일에 지역상인회에서 "8명만 모이는 작은 회식" 약속
3. 준영이 약속 생성 시 멤버 picker에서 25명 default → 17명 체크 해제, 8명만 남김
4. 약속 채팅이 별도로 생성되므로 그룹 상시 채팅을 시끄럽게 안 만듦
5. 같은 주 다른 날 "치킨집사장모임" 그룹에서 신메뉴 회의 약속
6. 두 약속 모두 홈 화면에 다가오는 순서로 정렬, 알림도 각각

**가치 포인트:** 그룹 부분 모임, 약속별 채팅으로 그룹 채팅 보호, 다중 그룹 관리.

## 시나리오 8 — 약속 취소 / 노쇼 (예외)

**페르소나:** 지수 (P1)
**상황:** 약속 1시간 전, 한 명이 갑자기 못 옴.

1. 지수가 약속 채팅에 "오늘 못 가게 됐어 ㅠㅠ"
2. 약속 만든 친구가 약속 편집 → 멤버에서 지수 제거
3. 지수의 약속 목록에서 해당 약속 사라짐, 위치공유 자동 시작 안 함
4. 만약 인원 부족으로 모임 자체 취소 → 만든 사람이 약속 상태 **'cancelled'** 로 변경
5. 모든 참여자에게 취소 푸시. 채팅방은 즉시 아카이브. 위치공유 시작 안 함

**가치 포인트:** 부분 이탈 vs 전체 취소 분리, 위치공유 안 시작되도록 안전 처리.

## 시나리오 9 — 프라이버시 우려 (위치 공유 거부)

**페르소나:** 서연 (P3)
**상황:** 약속에는 가지만 위치 공유는 하기 싫음.

1. 약속 상세 화면에 본인 토글: **"이 약속에서 내 위치 공유 안 함"**
2. 토글 OFF 시 — 본인 모바일 위치공유 시작 안 함, 다른 멤버 지도에 본인 핀 표시 안 됨
3. 다른 멤버의 위치는 여전히 볼 수 있음 (수신은 가능, 송신만 차단)
4. 약속별 설정이라 다음 약속에는 영향 없음

**가치 포인트:** 위치공유는 강제 아닌 선택. 친구 사이 신뢰 기반.

## 시나리오 10 — 그룹 방장 위임 / 탈퇴 (관리)

**페르소나:** 태훈 (P4)
**상황:** 등산 동호회를 다른 사람에게 넘기고 본인은 탈퇴.

1. 태훈이 그룹 멤버 화면 → 부회장 멤버에게 **"방장 위임"** 탭
2. 확인 다이얼로그 → 부회장이 owner로 승격, 태훈은 admin으로 강등
3. 태훈이 본인 멤버에서 **"그룹 나가기"** → 그룹에서 제거
4. 진행 중인 약속에서는 자동으로 빠짐
5. owner가 떠나면 그룹은 새 owner 책임으로 계속 운영

**가치 포인트:** 그룹 운영 권한 안전한 이전, owner 부재 방지.

## 시나리오 11 — 약속 시간이 지났는데 채팅 계속 (사후 정리)

**페르소나:** 민호 (P2)
**상황:** 약속 끝났지만 사진 공유 등 사후 대화 필요.

1. 약속 종료 시각 도달 → 채팅방 자동 아카이브 (`archived_at` 세팅)
2. 아카이브된 채팅방은 채팅 목록에서 별도 섹션 ("지난 약속")
3. 진입은 가능, 메시지 송수신도 가능 (단, 새 메시지는 아카이브 해제 안 됨)
4. 민호가 "사진 공유" 메시지 + 이미지 첨부 → 다른 참여자도 받음
5. 위치 공유는 종료됨. 종료 24시간 후 위치 핑 자동 삭제

**가치 포인트:** 사후 정리는 가능하되 화면 정리 (지난 약속 섹션).

## 시나리오 12 — 잘못 보낸 메시지 (편집/삭제)

**페르소나:** 혜진 (P5)
**상황:** 채팅에 잘못된 정보 보냄.

1. 본인 메시지 길게 누름 → "편집" / "삭제"
2. 편집: 텍스트 수정, `edited_at` 표시
3. 삭제: soft delete (`deleted_at`), 다른 멤버에겐 "삭제된 메시지" 로 표시

**가치 포인트:** 실수 복구 가능, 투명한 편집 표시.

## 시나리오 14 — 해외 여행 / 시차 (엣지)

**페르소나:** 지수 (P1)
**상황:** 친구가 일본 여행 중인데 한국에서 약속을 잡아둠.

1. 약속은 한국 시간 기준 저장 (timestamptz)
2. 일본에 있는 친구의 모바일은 현지 시간으로 표시 (KST 19:00 → JST 19:00 표시)
3. 위치 공유는 약속 시간이 되어도 멤버가 한국에 없으면 한국 지도에 의미 없는 핀 표시 → UX는 그대로 유지하되 다른 멤버에게 "○○님은 1500km 떨어진 곳에 있어요" 같은 안내 가능 (Phase 2)

**가치 포인트:** Timezone 정확성, 원거리 멤버에 대한 부드러운 안내.
