# MeetPod 3인 테스트 시나리오

> **테스터 역할**
> - **A (주도자)**: 그룹 생성 및 약속 주최
> - **B (멤버 1)**: 초대받는 일반 멤버
> - **C (멤버 2)**: 초대받는 일반 멤버

---

## 준비

1. 세 명 모두 TestFlight(iOS) 또는 APK(Android)로 앱 설치
2. 각자 Google 계정으로 로그인
3. 닉네임 설정 (영문/숫자/_ 3~20자)

---

## 시나리오 1 — 친구 추가

| 순서 | 담당 | 행동 | 확인 |
|------|------|------|------|
| 1 | A | 나 탭 → 친구 → 초대 링크 생성 | 8자리 코드 또는 링크 생성됨 |
| 2 | A | B에게 초대 링크/코드 공유 | - |
| 3 | B | 링크 탭 → 앱에서 열기 → 친구 추가 수락 | A가 B 친구 목록에 나타남 |
| 4 | A | C에게 동일하게 초대 링크 공유 | - |
| 5 | C | 친구 추가 수락 | A-C 친구 연결 |
| 6 | B | A에게 초대 링크 생성해서 공유 → C도 동일 | B-C 친구 연결 |

**확인 포인트**
- [ ] 3인 모두 서로 친구 목록에 표시되는가
- [ ] 만료된 코드로 재시도 시 오류 메시지 나오는가

## 시나리오 2 — 그룹 만들기

| 순서 | 담당 | 행동 | 확인 |
|------|------|------|------|
| 1 | A | 그룹 탭 → 그룹 만들기 → 이름 입력 ("테스트 모임") | 그룹 생성됨 |
| 2 | A | 그룹 상세 → 멤버 초대 → B, C 선택 | 초대 발송 |
| 3 | B, C | 알림 또는 앱 내에서 초대 수락 | 그룹 목록에 "테스트 모임" 표시 |
| 4 | A | 그룹 멤버 화면에서 B를 관리자로 지정 | B 역할이 admin으로 변경 |

**확인 포인트**
- [ ] B, C 화면에서 그룹이 보이는가
- [ ] 멤버 목록에 역할(방장/관리자/멤버)이 표시되는가

## 시나리오 3 — 약속 잡기

| 순서 | 담당 | 행동 | 확인 |
|------|------|------|------|
| 1 | A | 약속 탭 → 새 약속 | - |
| 2 | A | 제목: "점심 테스트", 일시: 오늘 + 1시간 뒤, 장소 검색 후 선택 | 지도 핀 선택됨 |
| 3 | A | 참여자: B, C 선택 → 위치공유 시작: 20분 전 | - |
| 4 | A | 저장 | 약속 목록에 표시됨 |
| 5 | B, C | 약속 탭 확인 | 약속이 각자 화면에 표시 |

**확인 포인트**
- [ ] 약속 상세에 제목/일시/장소/참여자가 올바르게 표시되는가
- [ ] B, C에게 약속 생성 푸시 알림이 오는가

## 시나리오 4 — 채팅

| 순서 | 담당 | 행동 | 확인 |
|------|------|------|------|
| 1 | A | 채팅 탭 → "테스트 모임" 그룹 채팅 입장 | - |
| 2 | A | "안녕하세요!" 전송 | B, C 화면에 실시간으로 메시지 나타남 |
| 3 | B | 답장 전송 | A, C에게 표시 |
| 4 | C | 이미지 전송 (🖼 버튼) | 이미지 말풍선으로 표시 |
| 5 | A | 📍 버튼 → 장소 검색 → 공유 | 장소 카드가 채팅에 표시 |
| 6 | B | 약속 채팅방 (점심 테스트) 입장 → 메시지 전송 | - |

**확인 포인트**
- [ ] 메시지가 실시간으로 3인 모두에게 전달되는가
- [ ] 이미지/장소 카드가 정상적으로 표시되는가
- [ ] 그룹 채팅 vs 약속 채팅이 구분되는가

## 시나리오 5 — 위치 공유

> 약속 시간을 **지금 + 25분**으로 새로 만들어야 합니다 (20분 전 자동 시작 테스트).
> 빠른 테스트는 약속 시간을 **지금 + 5분**으로 설정 후 위치 공유 시작을 **10분 전**으로 설정.

| 순서 | 담당 | 행동 | 확인 |
|------|------|------|------|
| 1 | A | 약속 생성: 지금 + 5분, 위치공유 시작: 10분 전 | - |
| 2 | 전원 | 앱을 백그라운드로 내려놓기 | - |
| 3 | (자동) | 약속 10분 전 도달 → 위치 공유 자동 시작 | 위치 공유 시작 알림 |
| 4 | A | 약속 상세 → 지도 보기 | B, C 위치 핀이 지도에 표시 |
| 5 | B | 실제로 이동 | A 화면에서 B 핀이 움직임 |
| 6 | C | 약속 상세 → 위치 공유 끄기 토글 | C 핀이 지도에서 사라짐 |

**확인 포인트**
- [ ] 위치 핀이 지도에 실시간으로 표시되는가
- [ ] 위치 공유 거부 시 핀이 사라지는가
- [ ] 약속 종료 후 위치 공유가 자동으로 멈추는가

## 시나리오 6 — 약속 수정 및 취소

| 순서 | 담당 | 행동 | 확인 |
|------|------|------|------|
| 1 | A | 약속 상세 → 수정 → 장소 변경 | B, C에게 변경 알림 |
| 2 | B | 약속 상세 확인 | 변경된 장소가 반영됨 |
| 3 | A | 다른 약속 → 취소 | B, C에게 취소 알림 |
| 4 | B, C | 약속 목록 확인 | 해당 약속이 목록에서 사라짐 |

**확인 포인트**
- [ ] 수정/취소 시 다른 참여자에게 푸시 알림이 오는가
- [ ] 변경 내용이 즉시 반영되는가
